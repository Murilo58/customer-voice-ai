## Decisões e desvios documentados

1. **Provedor de IA simulado** (`AI_PROVIDER=simulated`): o cliente Gemini só será implementado após a PoC 2. A interface `TriageProvider` isola a troca.
2. **Fila:** sem Vercel Queues por ora (exige deploy). O job roda após a resposta (`after()`) e o varredor `/api/internal/jobs` (protegido por `CRON_SECRET`; cron diário no Hobby) recupera pendentes. `npm run jobs:work` faz o papel no desenvolvimento.
3. **Papel `app_system` ainda não criado:** a outbox e o orçamento global são tabelas de plataforma sem dados pessoais, acessadas pelo `app_runtime`; o processamento de cada tarefa ocorre sob `withTenant`. Criar o papel dedicado junto com os crons do I-3 (SLA).
4. **Achado:** o `@default(now())` do Prisma usa o relógio do cliente; diferença de relógio impedia a reivindicação de jobs recém-criados. `run_after` passou a usar o relógio do banco.
5. Execuções com falha também ocupam a chave de idempotência; para tentar de novo com o mesmo conteúdo, o Gestor força o reprocessamento com justificativa.
